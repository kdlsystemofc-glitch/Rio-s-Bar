# KDL LANDING MANIFESTO V2.0
## Reference Architecture + Client Brand Sovereignty

# PURPOSE
Build a production-quality landing page from real client evidence while reproducing the structural sophistication of one approved reference.

# NON-NEGOTIABLE LAW
REFERENCE DNA controls ARCHITECTURE.
CLIENT DNA controls IDENTITY.
HUMAN REVIEW controls APPROVAL.

These systems must never be collapsed into one another.

## CLIENT DNA — SOVEREIGN
Logo, brand palette, typography personality, photography atmosphere, materials/textures, graphic motifs, copy voice, products/services, location and contact facts come from the CLIENT only.
If evidence is absent, mark UNKNOWN and use a restrained neutral utility. Never import a reference brand choice merely to fill a gap.

## REFERENCE DNA — STRUCTURAL
Page silhouette, composition, proportions, whitespace, hierarchy, type geometry, image geometry, scene rhythm, layering, overlaps, navigation behavior, motion grammar, scroll behavior, interactions and responsive composition may be reverse-engineered from the reference.

# REFERENCE EVIDENCE PACK
The Factory may provide:
- referencia/reference-hero.png — stabilized first fold
- referencia/reference-full.png — global silhouette
- referencia/reference-scenes/*.png — real viewport states across scroll
- referencia/reference-capture.json — capture diagnostics
- referencia/reference-url.txt — behavioral source when local evidence is insufficient

Do not treat a single full-page PNG as the only truth for animated/parallax/sticky sites.

# BRAND SOVEREIGNTY LOCK
Before reference analysis, Phase 01 must create docs/02A-CLIENT-BRAND-LOCK.md. Later phases may translate reference structure into this identity but may not overwrite it.

# NO GENERIC AI FALLBACK
Do not replace difficult reference mechanisms with generic cards, repeated 3-column grids, centered section headings, generic text-left/image-right blocks, pill overload, random glassmorphism/glows, or fade-up everywhere unless the reference genuinely uses them.

# IMAGE-FIRST DESIGN
Use real client imagery as compositional material through crop, mask, object-position, layering, isolation and controlled overflow. Do not make images look pasted into a template.

# TYPOGRAPHY
Client owns type personality. Reference may control geometry: scale, width, alignment, hierarchy and line-break logic.

# MOTION
Motion is architecture. Reproduce meaningful behaviors, not universal animation presets. Respect prefers-reduced-motion.

# CONTENT TRUTH
Never fabricate ratings, reviews, prices, dates, addresses, hours, products or claims. Separate VERIFIED / INFERRED / UNKNOWN.

# HUMAN GATES
Phase 03 Hero and Phase 05 full landing require explicit human approval. 03R/05R correct only the rejected material; they do not restart discovery.

# POINT MAINTENANCE
A finished landing may later receive isolated maintenance. A point fix must preserve all unrelated approved design and use a fresh maintenance conversation; it must never rerun the complete nine-phase workflow.

# FINAL TESTS
REFERENCE TEST — structural DNA clearly comes from the reference.
CLIENT TEST — identity unmistakably belongs to the client.
ANTI-CONTAMINATION TEST — unsupported reference colors/fonts/motifs did not leak into client identity.
ANTI-GENERIC TEST — no generic AI fallback.
SIBLING TEST — not interchangeable with another KDL client.
MOBILE TEST — intentionally recomposed.
FUNCTIONAL TEST — links/interactions/runtime work.
